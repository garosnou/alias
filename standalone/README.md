# Alias — турнир в зале

Самодостаточная версия для игры с экраном в зале. Ведущий и зал — два окна на одном компьютере. Во время игры интернет не нужен, внешних CDN нет.

Папка собирается и выкладывается отдельно от остального репозитория. Игровой код внутри не ссылается на файлы выше `standalone/`.

## Как открыть

1. Ведущий открывает `index.html` или `host.html`.
2. На панели ведущего нажимает «открыть зал в новом окне» — это `display.html`.

С диска зал открывают этой кнопкой. Окно, которое открыл ведущий, получает состояние через `postMessage`. Тот же кадр уходит в `BroadcastChannel` и `localStorage`: если браузер считает все `file://` одним источником, вторая вкладка `display.html` тоже обновляется. Кнопка не зависит от этой особенности. С адреса `http://127.0.0.1/…` зал можно открыть и отдельной вкладкой.

`index.html` сразу показывает панель ведущего. Так работает и каталог `/tournament/` на сайте.

## Сборка

Из этой папки, без установки зависимостей:

```bash
npm run build
```

- `npm run bg` — список картинок `bg/` в `bg/manifest.json` и `bg/manifest.js`
- `npm run zip` — архив `download/alias.zip`

Архив — то, чем играют с диска. В него не входят `download/`, `scripts/`, `package.json`, `PLAN.md` и `.gitignore`.

Собрать можно и одну скопированную папку, без корня репозитория. Из корня те же команды доступны ярлыками `node scripts/gen-bg-manifest.js` и `node scripts/build-standalone-zip.js`.

## База слов

`words.js` здесь — единственная копия базы. Корневая игра подключает этот же файл (`index.html` → `standalone/words.js`).

Файл не копируется при сборке. Копия в корне разошлась бы с этой, а сборка из `../words.js` не запустилась бы в папке, взятой отдельно. Игровой `host.html` по-прежнему грузит соседний `words.js`, без пути наружу.

## Выкладка

После попадания в `main` GitHub Actions собирает эту папку и заливает её по FTP теми же секретами, что и весь сайт:

- весь репозиторий — в каталог сайта, поэтому старая ссылка жива: `/standalone/download/alias.zip`;
- эта папка отдельно — в `/tournament/`.

На сайте:

- панель ведущего — `/tournament/` и `/tournament/host.html`;
- экран зала — `/tournament/display.html`;
- архив — `/tournament/download/alias.zip`.

Отдельный редирект со старого архива не нужен: по прежнему пути лежит тот же файл, собранный в том же запуске.

## Фоны

Картинки экрана «Подготовка турнира» лежат в `bg/`. Список обновляет `npm run bg` или кнопка «Обновить фоны» у ведущего.
